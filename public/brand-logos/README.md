exists it appears automatically in that brand's dashboard and (for the group
logo) across the marketing pages — no code change needed. Until a file is
present, a coloured letter mark is shown as a fallback.

## Tips

- **PNG with a transparent background** works best (SVG also fine — if you use
  SVG, rename the reference in `lib/brands.ts`, or just send me the SVGs).
- Roughly square or slightly wide is ideal; they're displayed small (~32px).
- Aim for a clean logo mark (icon) rather than the full horizontal lockup,
  since the space is compact.

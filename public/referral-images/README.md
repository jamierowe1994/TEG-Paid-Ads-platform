# Referral card images

Drop a photo in here for each brand and it appears as the background of that
brand's card in the mobile "Refer & earn" rolodex.

## Filenames

Name the file after the brand id, `.jpg`:

| File                    | Brand                            |
| ----------------------- | -------------------------------- |
| `property.jpg`          | The Property Experts             |
| `lettings.jpg`          | The Lettings Experts             |
| `mortgage.jpg`          | The Mortgage Experts             |
| `recruitment.jpg`       | The Recruitment Experts          |
| `commercial.jpg`        | The Commercial Property Experts  |
| `fineandcountry.jpg`    | Fine & Country                   |
| `auction.jpg`           | The Auction Experts              |

`.png` also works — the card tries `.jpg` first, then `.png`.

## What makes a good image

- **Portrait-ish or square** — the card is tall (roughly 3:4). Landscape shots
  still work, they just crop to the centre.
- **~1200px on the long edge**, saved around 80% quality. These load on mobile,
  so keep each file under ~300KB.
- **Busy centres are fine** — the card lays a faint blur, a brand-colour wash and
  a dark gradient over the top, so the type stays readable whatever the photo.
- **Avoid photos with text in them** — it fights the brand lockup.

## No image yet?

Nothing breaks. A brand with no file just shows its flat brand colour, exactly
as it does today. Add files one at a time and each card lights up on its own.
